Gerar o e-mail do report

Lê o arquivo de dados do mês, confere tudo, prepara as imagens e gera o arquivo .eml que o Outlook abre como mensagem nova.

1Escolha a pasta do projeto

Clique no botão e escolha a pasta principal do report (a que tem as pastas dados, assets e template). O navegador pergunta se quer "carregar" os arquivos: confirme. É só leitura, nada sai do seu computador.

Editou o arquivo depois de escolher a pasta? Clique em Selecionar a pasta de novo para ler a versão salva.

2Conferência

3Teste os links

Clique em cada link e confira se abre a peça ou o vídeo certo (com som, no caso do vídeo). Antes do envio geral, peça para uma pessoa de outra equipe testar também: é o único jeito de ter certeza de que o público do e-mail tem acesso. Passo a passo em docs/LINKS_SHAREPOINT_STREAM.md.

OndeBotão no e-mailLink

4Gere os arquivos

Depois de baixar: como abrir e enviar
  1. Na pasta Downloads, dê dois cliques no arquivo .eml. O Outlook abre uma mensagem nova com o report e o assunto preenchidos.
  2. Envie primeiro só para você. Abra o e-mail recebido no computador e no celular e clique nos links.
  3. Tudo certo? Abra o .eml de novo, coloque os destinatários e envie.
  4. Guarde o .html na pasta reports/: é o arquivo do mês.

Se o .eml abrir como mensagem recebida (sem botão Enviar), use Encaminhar e apague o cabeçalho que o Outlook coloca no topo. Detalhes em docs/HOW_TO_EXPORT_EML.md.
