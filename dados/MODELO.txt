#  e troque cada [texto entre colchetes]. Mais simples ainda: copie o
#  arquivo do mês anterior e troque só o que mudou.
#
#  Regras:
#   1. Cada linha é "campo: valor". Troque só o que vem depois dos ":".
#   2. Linhas que começam com # são instruções. Não vão para o e-mail.
#   3. Os [BLOCOS EM COLCHETES] organizam o arquivo. Não renomeie.
#      Para tirar um item (um lançamento, um número), apague o bloco
#      inteiro. Para recolocar, copie um bloco igual e troque o número.
#   4. Campo vazio = aquele elemento não aparece.
#      Ex.: "link:" vazio = a peça aparece, mas sem "Ver peça".
#   5. Texto [entre colchetes] dentro de um valor = PENDÊNCIA.
#      A ferramenta lista e só gera a versão final quando não houver.
#   6. Quebra de linha forçada num título: escreva <br>.
#
#  Imagens: coloque o arquivo na pasta indicada em "pasta_imagens" e
#  escreva só o nome (ex.: openai-ads.jpg). Pode ser a imagem original,
#  em alta: a ferramenta recorta e reduz para o e-mail sozinha.
#
#  Tipos de link (campo "tipo"), cada um com o seu texto fixo:
#    peca     -> "Ver peça →"          imagem ou peça em tamanho grande
#    video    -> "▶ Assistir"          vídeo (Stream / SharePoint)
#    projeto  -> "Ver projeto →"       página, documento, apresentação
#    demo     -> "Ver demonstração →"  protótipo ou demonstração
#  Que link colar: docs/LINKS_SHAREPOINT_STREAM.md
#
#  Depois de salvar: abra tools/gerar-report.html no Edge.
