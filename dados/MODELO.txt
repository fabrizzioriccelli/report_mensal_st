#  ESTE É O ÚNICO ARQUIVO QUE VOCÊ EDITA TODO MÊS.
#
#  Para começar um mês novo:
#    1. Copie este arquivo e renomeie a cópia para dados/AAAA-MM.txt
#       (ex.: dados/2026-10.txt). Ou copie o arquivo do mês anterior.
#    2. Troque o conteúdo de exemplo pelo conteúdo do mês:
#         Lorem ipsum…  -> textos       X, X%, R$ X  -> números
#         [INSERIR …]   -> imagens e links
#    3. Abra gerar-report.html. Passo a passo: docs/COMO_ATUALIZAR_O_MES.md
#
#  Regras:
#   1. Cada linha é "campo: valor". Troque só o que vem depois dos ":".
#   2. Linhas que começam com # são instruções. Não vão para o e-mail.
#   3. Os [BLOCOS] sozinhos numa linha organizam o arquivo. Não renomeie.
#      Para tirar um item (um lançamento, um número), apague o bloco
#      inteiro. Para recolocar, copie um bloco igual e troque o número.
#      Para tirar uma seção inteira, apague todos os blocos dela.
#   4. Campo vazio = aquele elemento não aparece.
#      Ex.: "link:" vazio = a peça aparece, mas sem "Ver peça".
#   5. AINDA NÃO PREENCHIDO = Lorem Ipsum, X (X%, R$ X, XX/XX), "Mês",
#      "AAAA" ou [texto entre colchetes]. A ferramenta lista cada um, com
#      a linha, e só libera a versão final quando não sobrar nenhum.
#   6. Quebra de linha forçada num título: escreva <br>.
#   7. Não invente número para "completar" o layout: deixe o X até ter
#      o dado real.
#
#  Imagens: coloque o arquivo na pasta indicada em "pasta_imagens" e
#  escreva só o nome (ex.: imagem: campanha-x.jpg). Pode ser a imagem
#  original, em alta: a ferramenta recorta e reduz sozinha.
#  Foto do banco de imagens aprovado: escreva o caminho completo
#  (ex.: imagem: assets/fotos/foto-grupo-conversa-corredor-2368480077.jpg).
#  Lista das fotos e onde cada uma funciona: assets/fotos/README.md
#
#  Tipos de link (campo "tipo"), cada um com o seu texto fixo:
#    peca     -> "Ver peça →"          imagem ou peça em tamanho grande
#    video    -> "▶ Assistir"          vídeo (Stream / SharePoint)
#    projeto  -> "Ver projeto →"       página, documento, apresentação
#    demo     -> "Ver demonstração →"  protótipo ou demonstração
#  Que link colar: docs/LINKS_SHAREPOINT_STREAM.md
# ======================================================================
