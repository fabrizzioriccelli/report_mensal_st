## Padrão das imagens

- JPG para fotos e peças (até ~200 KB cada); PNG transparente para personagem e ícones.
- Exporte no dobro da largura exibida no report; o tamanho de cada espaço está no comentário `EDITAR AQUI · 07 IMAGENS`.
- Nomes simples, sem espaço nem acento: `visual-principal.jpg`, `destaque-2-1.jpg`, `video-1.jpg`.

Vídeos não ficam aqui: publique no Microsoft Stream e use a miniatura com o link no report.
