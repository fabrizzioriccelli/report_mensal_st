# Marca

| Arquivo | O que é |
|---|---|
| `logo-santander-branco.png` | **Logo usado no e-mail**: versão branca, na capa (104 px) e no rodapé (88 px). PNG transparente, 480 px de largura |
| `logo-santander.png` | Versão vermelha, para usos sobre fundo branco (não usada no e-mail hoje) |
| `svg/logo-santander.svg` | Arquivo vetorial original, recebido da área |
| `svg/logo-santander-branco.svg` | O mesmo vetor, com a cor trocada para branco |

- O nome do arquivo e a largura no e-mail ficam em `config/marca.txt`, bloco `[LOGO]`.
- Para trocar o logo, salve o novo PNG aqui com o mesmo nome (ou ajuste o nome em `config/marca.txt`) e gere o e-mail de novo.
- Use sempre a versão oficial. Não redesenhe, não distorça e não aplique a versão vermelha sobre o vermelho.
- Se o arquivo configurado não existir, o rascunho mostra um espaço tracejado "LOGO" e a versão final não é liberada.

**VALIDAR COM MARCA:** versão do logo para fundo vermelho, tamanho mínimo e área de proteção em e-mail.
