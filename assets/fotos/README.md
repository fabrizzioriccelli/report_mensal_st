# Fotos do banco de imagens aprovado

**Esta pasta fica vazia no GitHub.** As fotos do banco de imagens são licenciadas (Shutterstock) para uso do banco: os arquivos têm a marca "No use without permission". Por isso elas ficam **só** no computador do trabalho ou no repositório corporativo, e o `.gitignore` impede que subam para o GitHub pessoal.

**VALIDAR COM MARCA:** se a licença cobre o uso interno no report e o armazenamento no repositório corporativo.

Regras do Brand Guide (seções 3.7 e 3.10) seguidas nessa escolha:
- Sobre **fundo vermelho**, a foto deve ter **pouco vermelho** (por isso a do suéter vermelho não vai na capa).
- Imagens **enquadradas** com cantos arredondados (no report, 20 px: metade da margem).
- Fotos naturais, de pessoas reais e momentos genuínos. Use a foto **original**, sem filtros.

## Como usar

1. Copie a foto para esta pasta (`assets/fotos/`).
2. No arquivo do mês, escreva o caminho completo:
   ```text
   imagem: assets/fotos/foto-mulher-notebook-poltrona-2688448063.jpg
   descricao_imagem: Mulher trabalhando no notebook
   enquadramento: direita
   ```
3. A ferramenta reduz e recorta sozinha. Não amplie fotos pequenas.

As fotos **não** substituem peças de comunicação reais: quando houver a peça do mês, use a peça.
