# ======================================================================
#  EDITAR AQUI — FONTE OFICIAL DO BANCO
# ======================================================================
#  O e-mail não "leva" a fonte junto: cada pessoa vê a fonte que está
#  INSTALADA no computador ou celular dela. Por isso cada campo é uma
#  lista: a 1ª fonte da lista que existir no aparelho é usada.
#
#  Para usar a fonte oficial:
#    1. Confirme com Marca/TI o NOME EXATO da fonte instalada nas
#       máquinas (o nome que aparece no Word, na lista de fontes).
#    2. Coloque esse nome no COMEÇO da lista, entre aspas simples:
#         titulos: 'Nome Exato da Fonte', Georgia, 'Times New Roman', serif
#    3. Mantenha as fontes seguintes: são o plano B de quem não tem a
#       fonte oficial (celular pessoal, por exemplo).
#
#  OUTLOOK PARA WINDOWS lê só UMA fonte e, se ela não existir no
#  computador, troca por Times New Roman. Por isso ele tem campos
#  próprios, com uma fonte só. Coloque a fonte oficial aqui SOMENTE se
#  a TI confirmar que ela está instalada em TODOS os computadores que
#  recebem o report. Na dúvida, deixe Georgia e Arial.
#  -> VALIDAR COM TI / MARCA.
# ======================================================================
[FONTES]
