# Reports

A página de cada mês, **gerada** por `gerar-report.html` (botão "Baixar página do mês"). Ela é o arquivo histórico: as imagens (e as fontes Santander, se os `.otf` estiverem em `assets/fonts/`) vão dentro do próprio arquivo, então abre em qualquer navegador, mesmo sem a pasta `assets`.

**Esta pasta fica vazia no GitHub pessoal.** As páginas dos meses têm dados reais: guarde-as só no repositório corporativo ou na pasta da área.

| Arquivo | Mês |
|---|---|
| `AAAA-MM.html` | Um arquivo por mês enviado (ex.: `2026-10.html`) |

**Não edite estes arquivos.** Para mudar um mês, edite `dados/AAAA-MM.txt` e gere de novo. Meses já enviados não devem ser alterados.

O layout aprovado, sem dados, está em [`report_backup.html`](../report_backup.html). Guia: [docs/COMO_ATUALIZAR_O_MES.md](../docs/COMO_ATUALIZAR_O_MES.md).
