Emulador do report mensal

Abra, edite e salve o report completo; depois gere o e-mail-resumo (.eml) com um único botão para o report. Tudo no navegador, sem instalar nada.

1Abra o report

Começar um mês novo Abre o modelo em branco (o "coringa"): todas as seções, com textos e imagens de exemplo para trocar.
Continuar um report salvo Abre um report salvo antes (.html), por exemplo o do mês anterior, para editar ou só gerar o e-mail.
ou arraste o arquivo .html para cá
Avançado: imagens em arquivo ao lado do .html

Só para páginas salvas pelo Chrome como "Página da Web, completa" (com a pasta _files). Os reports salvos por este emulador já trazem tudo dentro.

2Edite e salve o report

Texto ou número: clique e escreva. Enter confirma; Shift+Enter quebra a linha. Imagem ou vídeo: passe o mouse e use "Trocar imagem" (ou "Trocar vídeo"). Link: passe o mouse em um link vermelho e use "Trocar link". Mais links ou imagens: passe o mouse no item (projeto, lançamento, destaque…) e use "+ Link" ou "+ Imagem" (até 3 por item). Item que não vale este mês: passe o mouse e use "Tirar item" (o último de um grupo fica: para tirar tudo, oculte a seção). Assunto novo (ex.: Testes): + Novo tópico: escreva o nome e escolha o layout (lista, colunas, cartões ou números). Até 4.

Cole aqui a resposta do Copilot (formato do Prompt 11 do guia: blocos como [NUMERO 1] e linhas valor: 12,5%). Os campos correspondentes da página são preenchidos; nada mais muda. Confira depois, campo a campo.

3Link do report completo

O botão do e-mail-resumo leva quem lê para o report completo (o arquivo salvo no passo 2). Vale qualquer link: o do ambiente corporativo autorizado (https://…, ou só empresa.sharepoint.com/…, que ganha o https://), o caminho do arquivo (C:\…, \\servidor\… ou file:///…, que abre só onde esse caminho existe: bom para testar no seu computador ou para uma pasta de rede da área; no Outlook na Web e no celular, link de arquivo não abre), mailto:, msteams: ou um endereço relativo (report-AAAA-MM.html). Espaço vira %20. Só endereço que executa código (javascript:) é recusado.

  1. Para enviar à área: publique o arquivo salvo (report do mês) no ambiente autorizado, copie o link de compartilhamento e cole aqui. Teste numa aba anônima (Ctrl+Shift+N): o report precisa abrir.
  2. Para testar no seu computador: abra o report salvo no Chrome ou no Edge e copie o endereço da barra (file:///…), ou, no Explorador de Arquivos, botão direito no arquivo › Copiar como caminho, e cole aqui.

4E-mail-resumo

Curto de propósito: o período, a frase do mês, até 3 indicadores e uma única chamada, "Acessar report completo". O resto fica no report completo.

Abra um report para ver os indicadores.

Vêm marcados os números do projeto principal. Pode trocar por outros indicadores da página. Nenhum número é criado aqui: só aparecem os que estão no report.
